Watch Party

Watch together in sync, with avatars in a virtual theater, reactions, chat and voice. Start a party from the 👥 button on any movie or episode in the web client.

How many people fit in a party, host included (2–8). The theater has 8 seats.
How far a guest may drift from the host before they're moved back in step. Raise this if guests on slow connections keep re-buffering.
Comma-separated. Browsers use these to find each other for voice chat; the audio itself goes directly between them. Add a TURN relay if some people can't hear each other, e.g. stun:stun.l.google.com:19302, turn:user:password@turn.example.com:3478. Leave empty to only connect people on the same network. Voice chat needs Jellyfin to be opened over https.
